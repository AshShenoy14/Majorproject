# Benchmarks

TransGraph-PPI was evaluated on the project's STRING v12 human PPI benchmark described below. Two external-dataset checks were also run against the unretrained checkpoints (see "External Benchmarks" below), but they are not a comparison against published methods' own reported numbers.

## 0. External Benchmarks (no retraining)

Both use the exact production inference path, including cold-start KNN reconstruction for proteins absent from the training graph (see `scripts/cold_start_eval.py`).

| Dataset | Source relationship to training data | Pairs | Accuracy | ROC-AUC | F1 |
| :--- | :--- | :---: | :---: | :---: | :---: |
| SHS27k (Chen et al.) | Same source (STRING), different curated snapshot; 81% of proteins byte-identical to training data | 15,248 | 0.698 | 0.802 | 0.612 |
| HuRI / HI-union (Luck et al. 2020) | Independent source (systematic yeast-two-hybrid), sampled 700/64,006 pairs | 1,394 | 0.523 | 0.573 | 0.144 |

The HuRI confusion matrix (`assets/evaluation/external_benchmark_huri.json`) shows the model predicting positive on only 5.7% of pairs against a true 50% positive rate -- a systematic bias toward predicting non-interacting on this out-of-distribution data, not random noise. This is the clearest evidence in the project that the model does not generalize to a different interaction-detection modality (Y2H vs. STRING's curated/predicted interactions).

All numbers here come from `assets/evaluation/final_test_metrics.json`, generated by `src/analysis/compare_models.py`.

## 1. Evaluation Setting

| Property | Value |
| :--- | :--- |
| Data | STRING v12 human positives plus sampled negatives; 12,323 proteins |
| Pairs (total / train / validation / test) | 201,712 / 161,369 / 20,171 / 20,172 (100,856 positive, 100,856 negative) |
| Split | Stratified 80/10/10 at the pair level, `random_state=42` |
| Disjointness | Pair-disjoint, not node-disjoint (every test protein also occurs in the training set) |
| Task | Transductive pair prediction; no claim of unseen-protein or cold-start generalization |
| Graph | Training positive edges only |
| Thresholds | F1-maximizing, selected on the validation set |
| Reported on | Test set, all 20,172 rows evaluated, single run |

## 2. Internal Model Component Comparison

This is an internal component and baseline comparison on the same held-out test split. It is not a comparison against published methods, and it is not a controlled ablation: the configurations were trained and evaluated independently, and no component was removed from the ensemble and retrained.

| Configuration | Role | Threshold | Accuracy | Precision | Recall | F1 | ROC-AUC | PR-AUC |
| :--- | :--- | :---: | :---: | :---: | :---: | :---: | :---: | :---: |
| Random Forest | Baseline | 0.47 | 0.8234 | 0.8114 | 0.8428 | 0.8268 | 0.9065 | 0.9124 |
| ESM-MLP | Sequence branch | 0.49 | 0.8711 | 0.8600 | 0.8865 | 0.8730 | 0.9438 | 0.9474 |
| GraphSAGE (Platt-calibrated) | Graph branch | 0.59 | 0.9042 | 0.9201 | 0.8852 | 0.9023 | 0.9487 | 0.9616 |
| XGBoost Ensemble | Combined model | 0.50 | 0.9213 | 0.9359 | 0.9046 | 0.9200 | 0.9708 | 0.9759 |

The ensemble has the highest value in every reported metric on this test split.

### Caveats
- Single run on a single split; no confidence intervals or significance tests.
- Because the split is not node-disjoint, all test proteins are present in the training graph. This may favor the graph branch, and it was not tested.
- The biological feature (`bio_score`) is not an input to the 7-feature meta-learner.
- A degree-only logistic regression reaches accuracy 0.7063 / ROC-AUC 0.7838 on the same test set (`assets/evaluation/audit/audit_after_data.json`).
- Whether the ensemble's gain comes from combining the branches specifically was not tested with a controlled ablation.

## 3. Literature Context

Published PPI predictors (for example PIPR, GNN-PPI and HIGH-PPI) report results on other datasets with different preprocessing, split protocols and evaluation settings. None of those datasets were run here, and no published numbers are placed next to this project's results.

## 4. Reproduction

```bash
python src/analysis/compare_models.py     # writes assets/evaluation/final_test_metrics.json
```
