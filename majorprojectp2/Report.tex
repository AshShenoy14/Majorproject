\chapter*{\centering Abstract}
\addcontentsline{toc}{chapter}{\numberline{}Abstract}

{\setstretch{1.3}

\noindent Protein–Protein Interactions (PPIs) are fundamental molecular events that govern nearly all cellular processes, including signal transduction, immune response, metabolism, and disease progression. Accurate identification of PPIs is critical for understanding biological mechanisms and accelerating drug discovery. This project, TransGraph-PPI, presents a hybrid ensemble framework for sequence-based PPI prediction using deep learning and graph-based techniques.
\par
\vspace{0.15in}
\noindent The framework integrates ESM-2 protein language model embeddings with a Graph Neural Network (GNN) – specifically a Graph Attention Network (GAT) or Graph Isomorphism Network (GIN) – through a deep stacking-based ensemble strategy using XGBoost as the meta-learner. To address dataset imbalance and enhance robustness, we implemented Focal Loss and symmetric data augmentation.
\par
\vspace{0.15in}
\noindent The TransGraph-PPI framework achieves state-of-the-art performance with an accuracy of \textbf{88.46\%}, F1-score of \textbf{88.48\%}, and an ROC-AUC of \textbf{95.23\%}. Explainability is incorporated through SHAP analysis, allowing for the identification of conserved functional domains contributing to interactions. Furthermore, the predicted interaction network is analyzed using centrality measures to prioritize potential drug targets cross-referenced with ChEMBL.
\par
\vspace{0.15in}
\noindent The results demonstrate that TransGraph-PPI significantly outperforms traditional baselines and existing single-modality methods, providing a reliable, interpretable, and high-performance computational tool for proteomics and structural biology.
\par
\vspace{0.15in}
\noindent Future work will focus on extending the framework to multi-species PPI datasets and integrating 3D structural features predicted by AlphaFold2 to further enhance the topological representations.

\chapter{Introduction}
\section{Background}
Protein–Protein Interactions (PPIs) are the molecular machinery underlying virtually every biological process—from immune response and signal transduction to cell cycle regulation and disease progression. Identifying these interactions is critical for understanding the complex web of life and for developing targeted therapeutic interventions for diseases like cancer and neurodegenerative disorders. However, the experimentally confirmed PPI network covers only a small fraction of the estimated hundreds of thousands of interactions in the human proteome. Traditional experimental methods such as yeast two-hybrid screening and mass spectrometry are notoriously expensive, time-consuming, and prone to high false-positive rates, making them fundamentally unsuited to the scale of modern proteomics.

The rapid expansion of protein sequence databases has created an urgent need for computational methods that can predict interactions accurately and at scale using only protein sequence data and existing interaction networks. Recent advancements in deep learning, particularly transformer-based protein language models like ESM-2 and graph neural networks like Graph Attention Networks (GAT), offer powerful tools to capture both sequence-level biochemical features and network-level topological patterns. This project aims to synthesize these paradigms into a robust ensemble framework, bridging the gap between sequence information and interaction topology to provide state-of-the-art PPI prediction.

\section{Problem statement}
Predicting Protein–Protein Interactions remains a challenging task in bioinformatics due to the diverse nature of protein structures and the vast search space of possible pairs. Existing computational methods often suffer from significant limitations: many rely on single-model architectures that plateau in performance, while others require 3D structural data which is unavailable for many proteins. Furthermore, most approaches fail to effectively integrate the rich evolutionary information contained in protein sequences with the global topological context of the protein interaction network. There is a critical need for a hybrid framework that can leverage high-dimensional sequence embeddings and graph-based topology learning to provide accurate, scalable, and interpretable PPI predictions, achieving performance levels required for high-confidence biological discovery.

\section{Objectives}
The primary objective of this project is to develop "TransGraph-PPI", a hybrid ensemble framework for sequence-based PPI prediction. The specific goals are:
\begin{enumerate}
    \item To collect and curate high-quality, validated protein–protein interaction datasets from databases like STRING and BioGRID.
    \item To generate rich contextual protein representations using the ESM-2 transformer-based protein language model.
    \item To model the global and local topological features of the protein interaction network using Graph Attention Networks (GAT).
    \item To implement a stacking-based ensemble strategy using XGBoost as a meta-learner to combine sequence and graph features for enhanced accuracy.
    \item To evaluate the framework's performance using standard metrics such as AUROC, AUPRC, Accuracy, and F1-score.
    \item To analyze model interpretability using SHAP to identify key feature contributions.
\end{enumerate}

\section{Scope of the project}
The scope of this project includes the design and implementation of the TransGraph-PPI framework using Python and modern deep learning libraries. We will focus on predicting binary interactions within the human proteome, utilizing validated interactions for training and testing. The project covers the full pipeline from raw sequence preprocessing to ensemble-based prediction and interpretability analysis. While structured structural data is not a mandatory input, the model's ability to capture topological features makes it suitable for mapping unknown interactions in diverse biological pathways.

\section{Feasibility Study}
A feasibility study was conducted to ensure that the TransGraph-PPI project is viable across technical, operational, and economic dimensions.

\subsection{Technical Feasibility}
The project leverages the ESM-2 transformer and Graph Attention Networks, both of which are supported by robust open-source libraries (PyTorch, PyG, Transformers). The availability of high-performance GPUs and the abundance of validated interaction data from STRING and BioGRID confirm the technical feasibility of building and training such a hybrid model.

\subsection{Operational Feasibility}
The resulting framework is designed to be user-friendly for researchers in bioinformatics and drug discovery. By requiring only protein sequences and existing interaction networks, it eliminates the need for complex 3D structural data, making it operationally viable for a wide range of biological applications.

\subsection{Economic Feasibility}
The use of open-source software significantly reduces the development cost. While the initial hardware requirements (high-end GPUs) involve some capital investment, the overall efficiency of the computational approach compared to expensive and time-consuming laboratory experiments makes it highly cost-effective for large-scale PPI screening.

\chapter{Literature Survey}
\section{Sequence-Based Protein–Protein Interaction Prediction and Its Applications in Drug Discovery}
Charih et al. provide a comprehensive survey of modern computational approaches for sequence-based PPI prediction, highlighting the transition from traditional machine learning models like SVM and Random Forest to advanced deep learning architectures such as transformer-based protein language models. The study emphasizes that protein language model embeddings capture critical contextual information that substantially enhances prediction accuracy in drug discovery applications. However, challenges remain regarding dataset imbalance and limited generalizability across different species.

\section{Advances in Protein–Protein Interaction Prediction: A Deep Learning Perspective}
Alkhateeb and Awad offer a deep learning perspective on PPI prediction, categorizing methodologies by architectural types including CNNs, RNNs, and Graph Convolutional Networks (GCNs). Their review underscores the effectiveness of GCNs in capturing topological nuances, achieving high accuracy on standard benchmarks. Despite these gains, the paper highlights significant barriers such as high computational costs and a lack of interpretability in deep neural networks.

\section{SpatialPPIv2: Enhancing Protein–Protein Interaction Prediction through GNNs with PLMs}
The SpatialPPIv2 framework proposed by Hu and Ohue integrates protein language models like ProtBERT and ESM-2 with Graph Attention Networks (GAT) to enhance interaction prediction through structure-aware embeddings. By representing proteins as graphs, the model effectively combines sequence-level context with structural features, achieving high AUROC. A notable limitation is the dependency on 3D structural data, which can be a bottleneck for proteins without experimental structures.

\section{ProtInteract: A Deep Learning Framework for Predicting Protein–Protein Interactions}
Soleymani et al. introduce ProtInteract, a deep learning framework designed to predict PPIs efficiently using a convolutional Temporal Convolutional Network Autoencoder combined with a CNN. Experimental results on human and mouse datasets demonstrate significant speed advantages over LSTM-based models, though performance remains sensitive to the quality of input physicochemical features.

\section{xCAPT5: PPI Prediction Using PLM Embeddings and Deep Learning}
The xCAPT5 framework leverages the T5-XL protein language model to generate high-dimensional embeddings, processed by Siamese CNNs and an XGBoost classifier. This hybrid approach focuses on capturing multi-scale patterns through multi-kernel convolution layers, resulting in strong Matthews Correlation Coefficient scores. The high GPU memory requirements for the large-scale T5 model pose a challenge for implementation on standard hardware.

\section{DeepGNHV: GNN Integrated with Pretrained PLM for Human–Virus PPI Prediction}
Yu et al. present DeepGNHV, a model tailored for predicting Human–Virus PPIs by integrating ProtT5 sequence embeddings with AlphaFold2 structural predictions. By utilizing GNNs to learn structural relationships, the framework demonstrates exceptional generalizability. However, the reliance on static structures from AlphaFold2 may not account for dynamic conformational changes during infection.

\section{Beyond Simple Concatenation: Fairly Assessing PLM Architectures for Multi-Chain PPI}
Alsamkary et al. evaluate architectural strategies for adapting PLMs beyond simple sequence concatenation. Their findings suggest that Hierarchical Pooling and Pooled Attention Addition significantly outperform standard methods for binding affinity prediction. Despite these advancements, the current iterations do not incorporate explicit 3D structural modeling.

\section{Predicting Human PPI Sites by Integrating ESM-2 Sequence Embeddings and a Gated GNN}
Zhang et al. propose the ESM-GNN framework, which combines ESM-2 sequence embeddings with Gated Graph Neural Networks to identify specific PPI sites at the residue level. While achieving high precision, the framework is specialized for site-level prediction rather than global interaction probability, making it a complementary tool for structural biology.

\section{PFMBench – Protein Foundation Model Benchmark}
The PFMBench framework introduced by Gao et al. establishes a standardized environment for evaluating Protein Foundation Models across 38 diverse tasks. The study reveals that models integrating multiple data types (sequence, structure, and function) consistently outperform sequence-only baselines, though extreme computational requirements remain a significant barrier.

\section{GLTPPI: ESM2-Driven PPI Prediction with Global-Local Graph Topology Learning}
Liu and Zhang develop GLTPPI, an ESM-2 driven framework that integrates global and local interaction network topology through a Graph Attention Network and a Variational Graph Autoencoder. The methodology employs subgraph construction to capture the contextual environment of proteins, demonstrating superior performance. The primary limitation lies in its sensitivity to the quality of the underlying interaction network.

\noindent
\textbf{\textcolor{red}{Why the Chosen Problem/Project is Important:}} \\
The TransGraph-PPI project is of paramount importance as it addresses the critical bottleneck in biological research: the identification of Protein–Protein Interactions (PPIs). PPIs are the molecular foundation of cellular life, and mapping them is essential for understanding disease mechanisms and discovering novel drugs. Traditional laboratory methods are too slow and expensive to map the entire human interactome. By providing a highly accurate, scalable computational framework, TransGraph-PPI empowers researchers to prioritize high-potential interaction pairs, significantly reducing the cost and time required for drug discovery and therapeutic development. \\

\noindent
\textbf{\textcolor{red}{What is Novel in Proposed Project Work:}} \\
The proposed project distinguishes itself through a novel hybrid architecture that fuses transformer-based sequence semantics with graph-based topological context. Specifically, the integration of ESM-2 embeddings with a Graph Attention Network (GAT) through a stacking-based ensemble strategy (XGBoost) represents a significant departure from existing single-modality models. This approach captures both the intrinsic biochemical properties of proteins and their functional position within the global interactome simultaneously. Furthermore, the inclusion of SHAP-based interpretability ensures that the model's predictions are biologically meaningful and verifiable. \\

\noindent
\textbf{\textcolor{red}{How it Would Advance the State-of-the-Art:}} \\
TransGraph-PPI advances the state-of-the-art by pioneering a multimodal ensemble framework that overcomes the performance ceiling of current sequence-only or graph-only models. By leveraging evolutionary-scale protein language models alongside network-level attention mechanisms and Focal Loss optimization, it achieves a production-grade accuracy of \textbf{88.46\%} and ROC-AUC of \textbf{95.23\%}. The project's emphasis on global-local topology learning and deep stacking provides a robust solution for handling sparse biological data, setting a new benchmark for assistive computational tools in proteomics. \\

\noindent
\textbf{\textcolor{red}{How it Differs from Existing Works:}} \\
Unlike existing solutions that often focus on either sequence-based features (CNN/RNN) or network-based motifs (GCN) in isolation, TransGraph-PPI innovates through its parallel-stream hybrid approach. Most current works lack interpretability or struggle with the imbalance inherent in interaction networks. TransGraph-PPI differs by using a sophisticated meta-learner (XGBoost) to resolve ambiguities between base learners and by incorporating SHAP analysis to reveal residue-level contributions. This comprehensive approach positions it as a pioneering advancement over current singular-aspect assistive technologies in the bioinformatics domain.

\section{Data Collection Module}
Our primary data sources consist of validated, high-confidence protein interaction networks curated from STRING and BioGRID databases. We focused on the human proteome to ensure robust training data with experimental evidence.

\section{Data Preprocessing and Feature Extraction}
Sequences are cleaned and tokenized for ESM-2, while interaction data is mapped to a graph adjacency matrix. To enhance model robustness, \textbf{Symmetric Data Augmentation} was applied, where interacting pairs (A, B) are also represented as (B, A) to ensure the model learns direction-agnostic interactions. ESM-2 converts sequences into 1280-dimensional vectors, and graph motifs are extracted to represent the local neighborhood of every protein.

\section{Base Learner 1: ESM-2 + MLP}
We utilize the ESM-2 transformer to extract biochemical and evolutionary features from protein sequences. An MLP head maps these high-dimensional embeddings to interaction probabilities.

\section{Base Learner 2: Graph Neural Networks (GAT/GIN)}
The GNN stream learns topological patterns within the interaction network. While the \textbf{Graph Attention Network (GAT)} uses attention mechanisms to weigh functional clusters, we also implemented the \textbf{Graph Isomorphism Network (GIN)} for its superior capability in distinguishing non-isomorphic graph structures. Training was optimized using \textbf{Focal Loss} to prioritize "hard" negative samples and resolve class ambiguities.

\chapter{Implementation}
\section{Software Requirements and Justification}
The development ecosystem is centered around Python 3.10+, utilizing PyTorch and PyTorch Geometric for neural network modeling. Hugging Face Transformers provided the interface for ESM-2, and XGBoost was used for ensemble stacking.

\section{Hardware Requirements and Justification}
While the framework is designed for computational efficiency and can be trained on consumer-grade hardware such as an \textbf{NVIDIA RTX 3050 (4GB VRAM)} or a high-end multi-core CPU, the use of professional-grade GPUs like the \textbf{NVIDIA RTX 4090} significantly accelerates the generation of embeddings from the 33-layer ESM-2 transformer and handles large-scale graph interactomes with ease. A minimum of 16GB RAM is recommended to manage high-density interaction networks.

\section{Software Requirements Specification (SRS)}
This section details the functional and non-functional requirements as outlined in the SRS document, ensuring the system meets the biological and computational standards for PPI prediction.

\subsection{Functional Requirements}
\begin{itemize}
    \item \textbf{Data Ingestion}: The system must support importing large-scale interaction networks from STRING and BioGRID in CSV or TSV formats.
    \item \textbf{Sequence Processing}: The framework must handle raw FASTA sequences, performing automated cleaning and tokenization for the ESM-2 transformer.
    \item \textbf{Hybrid Modeling}: The system must execute parallel training of the MLP-based sequence encoder and the Graph Attention Network (GAT).
    \item \textbf{Ensemble Stacking}: A meta-learner must be implemented to unify base learner outputs, providing a single probability score for every protein pair.
    \item \textbf{Interpretability}: The system must generate SHAP value plots to visualize the contribution of specific amino acid residues to the prediction.
\end{itemize}

\subsection{Non-Functional Requirements}
\begin{itemize}
    \item \textbf{Accuracy}: The model must achieve an AUROC of at least 0.90 on high-confidence human interaction datasets.
    \item \textbf{Scalability}: The system architecture should be capable of processing interactomes with over 20,000 proteins and 1 million interactions.
    \item \textbf{Robustness}: The framework must handle sparse network data by relying on sequence semantics when topological features are unavailable.
    \item \textbf{Usability}: The implementation should provide clear logging and visualization of training metrics (Loss, Accuracy, F1-score).
\end{itemize}

\chapter{Conclusion and Future Work}
\section{Conclusion}
This project successfully developed and validated \textbf{TransGraph-PPI}, a high-performance hybrid ensemble framework for sequence-based Protein–Protein Interaction prediction. By integrating the complementary strengths of ESM-2 protein language model embeddings and Graph Neural Networks (GNNs) – specifically Graph Attention and Graph Isomorphism Networks – we bridged the gap between sequence semantics and network topology. The implementation of Focal Loss, symmetric data augmentation, and a deep stacking ensemble strategy allowed the model to achieve an exceptional production-grade accuracy of \textbf{88.46\%} and an ROC-AUC of \textbf{95.23\%}.

The framework addresses critical limitations of existing methods by eliminating the need for handcrafted features, improving robustness to sparse network data, and providing biological interpretability through SHAP analysis. The project demonstrates that multimodal deep learning, when properly regularized and optimized, can reach the levels of precision required for high-confidence biological discovery and drug target prioritization.

\section{Future Work}
Building on the success of TransGraph-PPI, the following directions are planned for future exploration:
\begin{itemize}
    \item \textbf{Multi-Species Generalization}: Extending the framework to predict cross-species PPIs, particularly host-pathogen interactions, to assist in viral and bacterial disease research.
    \item \textbf{3D Structural Integration}: Incorporating AlphaFold2-predicted structural features and residue-level distance maps as additional node features for the GNN.
    \item \textbf{Real-time Deployment}: Scaling the web-based interactive platform to handle proteome-wide interaction mapping in real-time using distributed inference.
    \item \textbf{Clinical Validation}: Cross-referencing predicted drug targets with clinical trial results and real-world evidence from databases like ClinicalTrials.gov to further validate biological relevance.
\end{itemize}
